# ALFWorld

Complete the requested household task efficiently.

Observe the environment carefully before taking actions.

## Insights

- When an object is not found in its expected location, search nearby or in similar locations.
- If a task requires an object to be in a specific state (e.g., clean, hot, cool), ensure that state is achieved before proceeding.
