# ALFWorld

Complete the requested household task efficiently.

Observe the environment carefully before taking actions.

## Insights

- When a task requires an object to be in a specific state (e.g., clean, hot, cool), perform the state-changing action (e.g., clean, heat, cool) before moving the object to its destination.
- After turning on a desklamp, check nearby surfaces or objects that might have been previously obscured to locate the target item.
- When a task requires examining an object with a desklamp, turn on the desklamp first, then locate and take the target object before examining it.
- For tasks requiring an object to be in a specific state (e.g., hot, cool, clean), ensure the object is in that state before moving it to its destination.
