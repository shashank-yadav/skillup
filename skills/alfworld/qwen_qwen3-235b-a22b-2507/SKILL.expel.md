# ALFWorld

Complete the requested household task efficiently.

Observe the environment carefully before taking actions.

## Insights

- Use 'use' on desklamp before attempting to examine objects that require light.
- After turning on desklamp, check nearby surfaces for the target object.
- If an object is not found in one container, systematically check other containers of the same type.
- After turning on a light source, check nearby surfaces for objects that need illumination.
- When searching for an object, check all containers of the same type systematically before moving to other locations.
- After using a light source, check nearby objects that might need illumination before moving to other locations.
- When an object is not found in expected containers, check surfaces and alternative storage locations like shelves or tables.
