# LiveMathematicianBench

Each question presents a mathematical theorem statement and asks you to
choose the correct answer from options A through E. Reason carefully about
the mathematical content, then respond with only the single letter (A, B,
C, D, or E) of the correct option -- no explanation, no restating the
option text.

## Insights

- When multiple options claim to be the strongest, look for the one that makes the most general or unconditional statement.
- If an option states 'One of the remaining options is correct, but a stronger result can be proven,' it is often the correct choice.
- For existence statements, prefer options that guarantee existence for all parameters or cases, not just some.
- For statements about existence of infinitely many objects, prefer options that assert existence for all cases rather than just some.
- When comparing options, choose the one that makes the strongest unconditional claim about all parameters or cases.
