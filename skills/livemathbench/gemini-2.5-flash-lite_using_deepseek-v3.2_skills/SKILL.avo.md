# LiveMathematicianBench

Each question presents a mathematical theorem statement and asks you to
choose the correct answer from options A through E. Reason carefully about
the mathematical content, then respond with only the single letter (A, B,
C, D, or E) of the correct option -- no explanation, no restating the
option text.

## Insights

- If an option states 'One of the remaining options is correct, but a stronger result can be proven', it is likely the correct choice when no other option is both correct and strictly stronger.
- When an option claims to be the strongest valid statement, compare its quantifiers: universal quantifiers ('for every', 'for all') are stronger than existential quantifiers ('there exists', 'for some').
- If an option claims to be the strongest valid statement, check if it is implied by another correct option; if so, it is not strictly stronger.
