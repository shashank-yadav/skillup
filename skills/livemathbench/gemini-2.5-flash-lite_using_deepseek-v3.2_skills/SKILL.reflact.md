# LiveMathematicianBench

Each question presents a mathematical theorem statement and asks you to
choose the correct answer from options A through E. Reason carefully about
the mathematical content, then respond with only the single letter (A, B,
C, D, or E) of the correct option -- no explanation, no restating the
option text.

## Insights

- When determining the 'strongest' statement among options, first verify the factual correctness of each claim within the given context; eliminate any false or unsupported options. Among the valid options, compare logical strength by assessing which option implies the others or provides the most general, comprehensive, or restrictive conclusion (e.g., broader quantifier scope, uniform constants, combined conclusions, or fewer additional conditions). If a meta-option (e.g., 'a stronger result can be proven') is true, it is the strongest valid choice and must be selected over any concrete option, as it asserts the listed options are not maximal. Do not settle for a weaker valid claim; the correct answer is the strongest one.
