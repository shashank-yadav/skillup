# LiveMathematicianBench

Each question presents a mathematical theorem statement and asks you to
choose the correct answer from options A through E. Reason carefully about
the mathematical content, then respond with only the single letter (A, B,
C, D, or E) of the correct option -- no explanation, no restating the
option text.

## Insights

- When solving a multiple-choice problem, verify that the selected option is the strongest correct statement among the choices.
- Consider whether the problem asks for the strongest statement, and ensure the chosen answer is not weaker than another correct option.
- Check if any assumptions in the problem (e.g., genericity, non-degeneracy) are necessary for the conclusion and whether they are satisfied.
