# LiveMathematicianBench

When presented with a multiple-choice question, the agent should:

1.  **Carefully read and understand the question:** Identify the core mathematical concepts, definitions, and conditions stated in the problem. Pay close attention to quantifiers (e.g., "for all," "there exists") and logical connectives.
2.  **Analyze the options:** For each option, determine if it logically follows from the problem statement and known mathematical principles.
3.  **Identify the strongest correct statement:** If multiple options appear correct, select the one that is the most precise, comprehensive, or specific, as indicated by the phrasing of the question (e.g., "strongest statement," "complete classification").
4.  **Respond with the single letter:** Output only the letter corresponding to the chosen option (A, B, C, D, or E). Do not include any explanations or restate the option text.
