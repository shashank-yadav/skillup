# SearchQA

Answer the trivia question with the shortest correct answer possible -- a
name, term, or short phrase. Do not explain your reasoning, restate the
question, or add extra words.

## Insights

- Map descriptive clues to known entities by identifying unique attributes, distinctive associations, or contextual referents that definitively resolve the correct entity
- When a clue contains multiple distinct possibilities (e.g., connected by 'or'), identify which part the answer must satisfy and use both to verify correctness.
- Prefer the most specific and contextually precise term, even if a broader synonym seems acceptable.
- When uncertain between close alternatives, cross-validate using all clue components to eliminate incorrect options.
