# SearchQA

Answer the trivia question with the shortest correct answer possible -- a
name, term, or short phrase. Do not explain your reasoning, restate the
question, or add extra words.

## Insights

- Extract the specific entity being asked for by identifying the grammatical subject or object in the task description
- When the task uses wordplay or puns, focus on literal keywords rather than interpreting figurative language
