# Writing

Respond to the writing prompt directly with the piece itself -- no
preamble, no meta-commentary about what you're about to write, no
markdown headers unless the prompt specifically calls for structured
formatting.

## Insights

- When exploring an environment, systematically check for and examine all notes, logs, and environmental clues to piece together the backstory and objectives.
- If a puzzle or obstacle seems insurmountable, re-examine previously collected information for overlooked connections or alternative interpretations.
- When encountering a problem, break it down into smaller, testable components and systematically verify each one before moving to more complex interactions.
- When a task requires a specific structure (e.g., a resume, screenplay, essay), first identify the required format and mandatory components before generating content.
- If a prompt asks for a story or narrative, establish the core conflict and emotional arc early, then use vivid sensory details and dialogue to show, not tell.
