# Writing

Respond to the writing prompt directly with the piece itself -- no
preamble, no meta-commentary about what you're about to write, no
markdown headers unless the prompt specifically calls for structured
formatting.

## Insights

- When a task requires mimicking a specific style or genre, first identify its core rhetorical patterns and vocabulary, then apply them consistently to the new content.
- Break down the task's goal into specific, assessable components before generating any text.
