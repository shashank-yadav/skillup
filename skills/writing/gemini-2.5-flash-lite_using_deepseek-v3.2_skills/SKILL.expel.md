# Writing

Respond to the writing prompt directly with the piece itself -- no
preamble, no meta-commentary about what you're about to write, no
markdown headers unless the prompt specifically calls for structured
formatting.

## Insights

- Read the full task description carefully before starting to generate a response.
- Identify and incorporate all specific requirements and constraints mentioned in the task.
- Structure the response to directly address each part of the task in a logical order.
- Use specific sensory details (sight, sound, smell, touch) to create immersive scenes.
- Show character relationships and internal conflicts through dialogue and subtle behavioral cues.
- Structure narratives with a clear beginning, middle, and end, even in outlines or short pieces.
- Use dialogue and behavioral details to show relationships and internal states, rather than just describing them.
- When a task specifies a tone or style, mirror that tone in the language and structure of the response.
- For tasks requiring a specific structure (e.g., essay, outline, script), follow that structure explicitly, using clear section breaks or formatting.
